Project 1: Signal Generation



This project generates and visualizes sinusoidal signals at 50 Hz and 100 Hz.



Parameters



Sampling frequency: 1000 Hz



Signal frequencies: 50 Hz and 100 Hz



Simulation duration: 0.1 seconds



How to Run



Open MATLAB.



Open signal\_generation.m.



Click Run to visualize the signals.
